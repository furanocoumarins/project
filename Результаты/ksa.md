# Ксантотоксин

**Токсичность:**

```
 Высокий риск гепатотоксичности (DILI = 0.863)
Канцерогенность (0.843) - обнаружены 4 генотоксичных субструктуры
енотоксичность (0.949)
здражение глаз (0.972)
блемы с рецепторами: активность AhR (0.704)
```

**Метаболизм:**

```
 Мощный ингибитор почти всех CYP450: CYP1A2, CYP2C19, CYP2D6, CYP3A4,
CYP2B6, CYP2C8 (все = 1.0)
Субстрат CYP3A4 (1.0) - быстрая метаболизация
нгибитор транспортеров OATP1B1/1B3 и MRP
```

**Фармакокинетика:**

```
 Низкая биодоступность (F20% = 0.772, F30% = 0.668)
Высокое связывание с белками плазмы (94.6%)
ороткий T1/2 (1.1 часа)
облемная проницаемость (MDCK = -4.562)
```

**Единственные плюсы:**

```
 Хорошее кишечное всасывание (HIA)
Не проникает через ГЭБ
оответствует правилам Липински, Pfizer, GSK
абилен в микросомах печени
```
